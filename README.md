# CucumberWdio
This Project is a sample automation framework using WebdriverIO with Cucumber framework.
The Framework is built with Javascript to support BDD for testing web application.

Features:
BDD using cucumber and gherkin syntax
WebdriverIO for interaction with browser
Page Objects and step definitions

Pre-requisites:
Node.js
npm
Code editor - VS code
Browser - Chrome
